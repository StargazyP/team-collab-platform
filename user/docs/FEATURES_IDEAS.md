# 추가하면 좋을 기능 제안

현재 구현된 기능(워크스페이스, 채널, DM, TODO, 허들, 알림)을 바탕으로, 우선순위와 난이도를 고려한 제안입니다.

---

## 🟢 비교적 쉽게 붙일 수 있는 것

| 기능 | 설명 | 참고 |
|------|------|------|
| **메시지 검색** | 채널/DM 내 메시지 제목·본문 검색 (API + 간단 검색 UI) | `message.service` 확장, `LIKE` 또는 Full-Text |
| **TODO 수정 페이지** | 새글 작성처럼 `/todos/[id]/edit`에서 제목·상세 수정 | 기존 `PATCH /api/todos/[id]`, `RichTextEditor` + `setHtml` |
| **마지막 읽은 위치** | 채널별로 마지막 읽은 메시지 ID 저장, 새 메시지 개수 배지 | `workspace_members` 또는 별도 테이블, WebSocket과 연동 |
| **다크 모드** | Tailwind 다크 클래스 + localStorage/쿠키로 테마 전환 | `next-themes` 또는 단순 토글 |
| **초대 링크** | 워크스페이스/채널 초대 링크 생성(토큰), 비회원도 가입 후 가입 시 자동 가입 | 초대 테이블 + 쿼리 파라미터 |
| **프로필 이미지** | 아바타 업로드·URL 저장 (S3/로컬 스토리지) | `users` 컬럼 추가, `/api/users/avatar` |

---

## 🟡 실시간·협업 강화

| 기능 | 설명 | 참고 |
|------|------|------|
| **타이핑 인디케이터** | "OOO님이 입력 중..." (채널/DM) | WebSocket 이벤트 타입 추가, 2~3초 디바운스 |
| **읽음 표시** | DM에서 상대가 메시지를 읽었는지, 읽은 시각 표시 | 메시지/읽음 테이블, WS 또는 폴링 |
| **메시지 반응(이모지)** | 메시지에 👍/❤ 등 반응 추가·취소 | `message_reactions` 테이블, 실시간 갱신 |
| **스레드(답글)** | 메시지에 대한 답글 스레드 UI + API | `parent_message_id`, 스레드 전용 목록 API |
| **화면 공유** | 허들 내에서 화면 공유 트랙 (LiveKit ScreenShare) | LiveKit 이미 지원, UI만 추가 |

## 🔴 규모 있는 기능

| 기능 | 설명 | 참고 |
|------|------|------|
| **파일/이미지 업로드** | 메시지·TODO에 이미지/파일 첨부, 미리보기·다운로드 | 스토리지(S3/로컬), `attachments` 테이블, 업로드 API |
| **음성 메시지** | 짧은 음성 녹음 후 메시지로 전송 | 녹음(MediaRecorder) → 파일 업로드 → 메시지 타입 구분 |
| **채널/DM 검색** | 워크스페이스 전체 메시지 검색, 필터(채널, 기간, 작성자) | 검색 전용 API, 페이지네이션 |
| **봇/슬래시 커맨드** | `/remind 3pm 회의` 같은 명령으로 TODO·알림 생성 | 메시지 파싱, 봇 서비스 또는 내부 API 호출 |
| **모바일 대응** | 반응형 + PWA(오프라인 알림) 또는 간단 앱 | Tailwind 반응형, manifest, service worker |

## 정리

- **먼저 해보기 좋은 것**: 메시지 검색, TODO 수정 페이지, 다크 모드, 프로필 이미지.
- **차별화에 도움**: 타이핑 인디케이터, 메시지 반응, 스레드, 화면 공유.
- **업무 도구처럼 쓰려면**: TODO 마감일·라벨·상세 페이지, 알림 설정.

원하는 방향(실시간 채팅 강화 / TODO·업무 강화 / UX·접근성)에 맞춰 위에서 골라 확장하면 됩니다.
