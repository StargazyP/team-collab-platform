# Workspace — Real-time Collaboration Platform

실시간 협업·커뮤니티 플랫폼 데모 (Next.js 기반)

## DEMO

- **배포 URL**: (배포 후 여기에 데모 주소를 넣어 주세요)
- 워크스페이스 생성·채널·DM·실시간 채팅, 보이스/비디오 허들, TODO 보드 등 체험 가능

## 주요 기능

- **워크스페이스** — 팀 단위 워크스페이스 및 역할 기반 접근
- **채널 / DM** — 공개 채널·1:1 메시지, 실시간 WebSocket 채팅
- **보이스·비디오 허들** — LiveKit 기반 실시간 음성/영상 회의
- **TODO** — 칸반 스타일 작업 보드 (Todo → Doing → Done)
- **알림** — 실시간 알림, @멘션, 메시지 검색

## 기술 스택 (요약)

- **Frontend**: React, Next.js (App Router), Tailwind CSS
- **Backend**: Next.js API Routes, TypeScript
- **Real-time**: WebSocket, LiveKit
