# Workspace — Real-time Collaboration Platform

Demo of a real-time collaboration and community platform (Next.js).

## DEMO
https://jangdonggun.duckdns.org/nextjs/login/
- **Live URL**: (Add your demo URL here after deployment)
- Try workspaces, channels, DMs, real-time chat, voice/video huddles, and TODO board

## Features

- **Workspaces** — Team workspaces with role-based access
- **Channels & DMs** — Public channels and 1:1 messages with real-time WebSocket chat
- **Voice / Video Huddles** — LiveKit-based real-time audio and video meetings
- **TODO** — Kanban-style task board (Todo → Doing → Done)
- **Notifications** — Real-time notifications, @mentions, message search

## Tech Stack

- **Frontend**: React, Next.js (App Router), Tailwind CSS
- **Backend**: Next.js API Routes, TypeScript
- **Real-time**: WebSocket, LiveKit
